## 1. 一个改了一半的技能

```markdown
## 规则
不得推测缺失的数据；未获取到就写"未获取"。

## 示例
输入：客户近三个月的订单
输出：近三个月订单额呈上升趋势（约 +12%）
```

> ⭐⭐⭐⭐⭐ 示例里那个"+12%"没有任何来源——
> 它是作者为了让示例"看起来完整"随手写的一个数。

于是正文说"不得推测"，示例示范了一次推测。⭐⭐⭐⭐⭐ **模型会跟着示例做。**

而这类技能上线后的典型事故是：输出里出现大量看起来专业、实际没有依据的推断，
排查方向是"正文是不是没写清楚"——⭐⭐⭐⭐⭐ 正文写得清清楚楚，是示例在反向教。

## 2. 为什么是示例赢

| | 指令 | ⭐ 示例 |
|---|---|---|
| 形态 | 一般性说法 | ⭐⭐⭐⭐⭐ **具体发生过的事** |
| 约束方式 | 描述规则 | ⭐⭐⭐⭐⭐ 直接示范行为 |
| 模型的信任度 | 较低 | ⭐⭐⭐⭐⭐ 较高 |

> ⭐⭐⭐⭐⭐ **模型对示例的信任度高于对指令的信任度**——
> 示例是"已经发生过的事实"，指令只是"一般性的要求"。

这和 `example-values-become-defaults.md` 是同一个机制的两个后果：

```
那份：示例里的值会被复制（因为信任度高）
⭐⭐⭐⭐⭐ 这份：示例里的行为会被模仿（同一个原因，后果更严重）
```

复制一个值，输出里出现一个可疑的数字——**可见**。
模仿一个行为，输出里出现一种做法——⭐⭐⭐⭐⭐ **不可见，因为它看起来就是正常输出**。

## 3. 三种最常见的冲突

| 冲突 | 表现 | ⭐ 关键点 |
|---|---|---|
| ⭐⭐⭐⭐⭐ 示例做了正文禁止的事 | 正文"不得推测"，示例里全是推测 | 最常见，也最贵 |
| ⭐⭐⭐⭐ 示例用了已废弃的字段/格式 | 正文改了输出契约，示例没改 | 输出 schema 与示例不一致 |
| ⭐⭐⭐⭐ 示例的详尽度与长度预算冲突 | 正文"每段 ≤5 行"，示例一段 20 行 | 长度要求被示例否决 |

第二种特别值得注意：**它让"改了输出契约"这件事只生效一半**——
schema 更新了，示例还在教旧格式，而示例的影响力更大。

第三种是"输出长度预算"失效的主要原因之一：⭐⭐⭐⭐⭐ 你写了"每段 ≤5 行"，
然后给了一个 20 行的示例——**模型学到的是 20 行**。

## 4. 为什么没人审示例

三个结构性原因，都不是疏忽：

```
① ⭐⭐⭐⭐⭐ 示例看起来不是指令
   它被归类为"演示材料"，于是评审时读的是正文，示例只扫一眼"格式对不对"

② ⭐⭐⭐⭐⭐ 示例通常是最后写的
   正文定稿后补一个示例，此时正文的约束已经不在脑中

③ ⭐⭐⭐⭐⭐ 示例常从真实输出抄
   它反映的是"当时实际发生了什么"，而正文反映的是"当初想让它做什么"
```

第③条最根本：

> ⭐⭐⭐⭐⭐ **示例和正文的时差，就是技能的"想法"与"做法"的时差。**
> 抄真实输出时，你抄的是模型当时的行为——包括它违反正文的那些部分。

## 5. 修法

```
① ⭐⭐⭐⭐⭐ 改正文时，把"示例是否需要同步"当作必检项
② ⭐⭐⭐⭐⭐ 示例不得包含正文未允许的动作（推测、编造、越权）
③ ⭐⭐⭐⭐ 示例的格式必须与当前输出契约一致（与 schema 同源）
④ ⭐⭐⭐⭐ 示例的详尽度必须落在长度预算内
⑤ ⭐⭐⭐⭐⭐ 把示例纳入回归：改动后用示例当用例跑一遍
```

第⑤条最有效，也最省：`examples-as-contract.md` 说示例是对 description 契约的测试——
⭐⭐⭐⭐⭐ **同一份示例也是对正文约束的测试**，只是没人这么用。

第②条有个可操作的检查：

> ⭐⭐⭐⭐⭐ **读示例，逐句问：正文哪一条允许了这个动作？**
> 答不上来 → 示例在教一件正文没允许的事。

## 6. 该保留的不一致

不是所有不一致都要消除。两种应当保留：

| 情况 | 为什么保留 |
|---|---|
| ⭐⭐⭐⭐ 示例故意展示"被纠正前的错误做法" | 它是反例，必须看起来错 |
| ⭐⭐⭐⭐⭐ 示例带脏输入（真实杂讯） | 它示范的是判断，不是格式 |

判据：⭐⭐⭐⭐⭐ **不一致是"示例在演示另一种东西"，还是"示例忘了更新"？**

前者有标记（反例有 ❌ 标记、有"应修正为"），后者没有标记。
**没有标记的不一致，一律按"忘了更新"处理。**

---

## 7. 自检

| 检查 | 不通过的信号 |
|---|---|
| ⭐⭐⭐⭐⭐ 示例里有没有正文未允许的动作？ | 有推测、有编造、有越权 |
| ⭐⭐⭐⭐⭐ 示例的输出格式是否与当前 schema 一致？ | 字段名对不上 |
| ⭐⭐⭐⭐ 示例长度是否落在正文的长度预算内？ | 示例比预算长 4 倍 |
| ⭐⭐⭐⭐⭐ 最后一次改正文，有没有同步示例？ | 改了输出契约，示例没动 |
| ⭐⭐⭐⭐ 不一致的地方有没有 ❌ /"应修正为"标记？ | 无标记的不一致 |
| ⭐⭐⭐⭐⭐ 把示例当规格读一遍，得出的规则和正文一样吗？ | ⭐⭐⭐ 不一样 = 模型学到的和你想的不一样 |
