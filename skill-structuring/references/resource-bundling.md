# 随技能打包资源：什么该放、什么不该放

> 目录里能放的东西比多数人以为的多——
> ⭐ **在被访问之前，打包多少都不产生上下文成本**。
> 但正因为如此，也很容易塞进不该塞的东西。

## 三类目录的分工

| 目录 | 放什么 | 判据 |
|---|---|---|
| `scripts/` | 小的 CLI 工具、确定性逻辑 | ⭐ **执行**，不进上下文 |
| `references/` | schema、API 文档、规则集 | **读进**上下文，一层深 |
| `assets/` | 输出模板、JSON schema、静态文件 | **被消费**，不是被读 |

判据一句话：**要每次结果一致 → `scripts/`；要每次有新见解 → `references/`。**

## 脚本：给每个脚本贴标签

一个很容易被忽略但很有用的约定：

```
每个 helper 都要标明：
  read-only   只查看状态
  bootstrap   初始化/准备
  mutating    ⭐ 会改变状态
```

为什么值得做：下游 agent（以及人）看到标签就知道
**这个脚本会不会动东西**，不需要读完全部源码才能判断。

配套的三条：

```
□ 用 stdout/stderr 向 agent 传达成功或失败
□ 单一职责——一个脚本解决一个"脆弱"任务
     （正则、复杂解析、重复的样板代码）
□ ⭐ 引用路径要"在 agent 的工作目录下无歧义"
     ——不要写裸的 scripts/helper.py，它会静默依赖 CWD
```

⚠️ 最后那条是真实故障源：agent 换了个工作目录，
`scripts/helper.py` 就找不到了，而且**不报错，只是做错**。

## 依赖不能假设已装

```
❌ "用 pdf 库处理这个文件"
   ——假设了安装，环境里没有就静默失败或乱试

✅ "先安装依赖：pip install pypdf
     然后：from pypdf import PdfReader"
```

**MCP 工具同理，要用完全限定名**：

```
❌ bigquery_schema
✅ BigQuery:bigquery_schema
```

多个 MCP server 并存时，不加前缀模型会找不到工具。

## 路径一律相对 + 正斜杠

```
❌ C:\Users\me\skills\my-skill\scripts\x.py
❌ /Users/me/skills/my-skill/scripts/x.py
✅ scripts/x.py
```

两个理由：换机器就断；Windows 风格反斜杠在很多解析里是转义字符。

需要指向技能目录本身时，用运行时占位符（如 `${CLAUDE_SKILL_DIR}`），
但要注意它**只在加载时被替换**——详见 `runtime-truth.md`。

## 四条"不要放"

**① 不要放给人看的文档**

```
❌ README.md / CHANGELOG.md / INSTALLATION_GUIDE.md
```

> ⭐ **技能是给 agent 用的。**
> 这些文件只会增加目录噪声，并在检索时稀释真正的指令。

版本历史要记就记在 `references/` 里以 agent 能消费的形式，
或者干脆放在技能目录之外（仓库级）。

**② 不要打包库代码**

```
❌ 把某个解析库的源码贴进技能
✅ 用 npm / pip 安装
```

库代码体积大、会过期、且你并没打算审它。

**③ 不要重教模型已经知道的东西**

```
❌ Python 语法教程
❌ "什么是 git"
```

判据很直接：**每一行都要提供模型本来没有的上下文**。
拿不准就做 no-op 测试——删掉这行，行为会变吗？
不变就删。

**④ 不要塞时效信息**

```
❌ "截至 2024 年 Q4，..."
```

会腐烂。要么用脚本实时抓取，要么明确标进 "old patterns" 章节。

## 执行意图要写清楚

同一份脚本，两种引用方式效果完全不同：

```
"运行 analyze_form.py 提取字段"        → 执行（不占上下文）
"参考 analyze_form.py 了解提取算法"    → 读进上下文（占 token）
```

> ⭐ **这一句之差，决定它是工具还是文档。**
> 指令里不写清楚，模型可能选择更贵的那条路。

## 一条收尾检查

写完目录后问自己：

```
□ 每个脚本都标了 read-only / bootstrap / mutating？
□ 引用的路径在任意 CWD 下都无歧义？
□ 有人类向文档吗？（有就删）
□ 有时效信息吗？（有就进 old patterns）
□ 有重教模型已知内容的段落吗？（有就删）
□ MCP 工具都带 server 前缀？
□ 每条路径都是相对 + 正斜杠？
```
