## 1. ⭐⭐⭐⭐⭐ 模型不会做同义消解

人读文档时，"配置项/配置/设置"会自动合并成一个概念。模型不会：

> ⭐⭐⭐⭐⭐ **对模型来说，两个词就是两个 token 序列，
> 它不会自动推断"作者这里换了个说法"。**

后果不是"理解偏差"，是**行为分叉**：

```
正文写：   "先校验配置"
后面写：   "确认设置无误后继续"
模型可能：执行了两次校验，或认为这是两个不同步骤
```

> ⭐⭐⭐⭐ 这跟"重复指令"是同一类错误：
> **你以为你在复述强调，模型以为你在说第二件事。**

---

## 2. ⭐⭐⭐⭐ 三种不一致

**① 同义混用**（最常见）

```
"报告 / 输出 / 结果 / 产物" 四个词指同一个东西
```

**② ⭐⭐⭐⭐⭐ 一词多义**（最危险）

```
"状态" 在一段里指运行状态，另一段里指审核状态
```

> ⭐⭐⭐⭐⭐ **第二种比第一种危险得多。**
> 同义混用只是冗余，一词多义是**歧义**——
> 而歧义会让模型选一个，且它不知道自己选错了。

这也正是 `skill-output/references/structured-output-pipeline.md` 那条
"没有 description 的字段等于省略了一半提示"的同源问题：
**名字相同不等于含义相同。**

**③ ⭐⭐⭐ 与外界不一致**

```
技能里叫 "workspace"，但用户和 UI 里都叫 "项目"
```

> ⭐⭐⭐ 这一类会导致**触发词失效**——
> 用户说"项目"，技能里全是 "workspace"。

## 3. ⭐⭐⭐⭐⭐ 最小术语表格式

不要做成词典，**三列就够**：

| 术语 | 含义 | ⭐ 不要用的说法 |
|---|---|---|
| 报告 | 本技能的最终输出文件 | ❌ 输出、结果、产物 |
| 校验 | 跑 validate.py 这一步 | ❌ 检查、确认、验证 |
| 会话 | 一次完整的执行 | ❌ 运行、流程 |

> ⭐⭐⭐⭐⭐ **第三列是关键。**
> 只有正面定义的表，模型不知道"遇到别的说法时该怎么办"；
> ⭐ 有了"不要用的说法"，它才知道那些词等同于这一项。

这一列同时解决了两种不一致：
同义混用（列出该用哪个）和一词多义（列出不这么用的那些）。

## 4. ⭐⭐⭐⭐ 该收哪些词

四条标准（满足任一即收）：

| 标准 | 例子 |
|---|---|
| ⭐⭐⭐ 出现 ≥3 次 | 高频词不一致的代价最大 |
| ⭐⭐⭐⭐ 有歧义风险 | "状态""配置""处理" |
| ⭐⭐⭐ 与外界叫法不同 | workspace vs 项目 |
| ⭐⭐⭐ 是输出字段或槽位名 | 字段名必须唯一 |

> ⭐⭐⭐⭐ 第二条最该优先：
> **"处理"是个万能动词，几乎必然有歧义**
> （处理文件 = 读？解析？转换？写回？）。

不该追求完整——**超过 15 个词的术语表没人维护，也没人读**。

---

## 5. ⭐⭐⭐ 不该收哪些

三条排除规则：

```
❌ 通用技术词（JSON、HTTP、API）——模型知道
❌ 只出现一次的词——不值得占 token
❌ ⭐ 业界已有唯一叫法的词（git commit）——收了只是噪音
```

> ⭐⭐⭐ 第一条与"不写模型已知道的概念"完全同源：
> **术语表的价值在于消除"你们这里特有的歧义"，
> 不在于教通用词汇。**

## 6. ⭐⭐⭐ 机械检查与维护

**检查**（可进 CI）：

```bash
# 找出疑似同义混用：同一段里出现多个候选词
grep -nE "报告|输出|结果|产物" SKILL.md
```

> ⭐⭐⭐ 人工看命中行即可，不需要自动判定——
> 判"是不是同义"需要理解，机器做不了；
> ⭐⭐ **但机器能做的是"让你看见它们出现在哪些行"**，
> 而这正是人工检查最缺的那一步。

**维护**（两条）：

```
1. ⭐ 新增概念时同步加一行（写进 PR checklist）
2. ⭐⭐⭐ 术语表放在正文靠前位置——见 instruction-ordering.md
   （中段是最低可靠区，术语表埋在那儿等于没有）
```

## 7. ⭐⭐ 与含糊词的关系

两者常被混为一谈，其实是两个不同的检查面：

| | 含糊词黑名单 | ⭐ 术语表 |
|---|---|---|
| 问题 | 单个词没有判据（"适当"） | ⭐ 多个词指向一个概念 |
| 后果 | 模型按默认值填充 | ⭐⭐ 模型当成两件事 |
| 修法 | 替换成可观察标准 | ⭐ 收敛到一个词 + 列出禁用说法 |

> ⭐⭐⭐ **顺序是先术语表，后含糊词**——
> 因为先统一了词，才能判断剩下的词是不是含糊
> （否则你会把"报告/产物"当成含糊词去改，其实只是没统一）。

## 一句可贴在墙上

> ⭐⭐⭐ **两个词就是两个概念——模型不会替你做同义消解。**
