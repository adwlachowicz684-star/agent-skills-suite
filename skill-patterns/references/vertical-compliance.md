> 共同点是：**错的代价极高，且规则来自外部而非团队内部**。

## 为什么垂直行业最先强制

```
□ ⭐ 错的代价极高（金额、健康、法律责任）
□ ⭐ 规则来自外部（监管、法规），不是团队自己定的
   ——意味着不能靠"我们习惯这样做"来解决
□ ⭐ 有明确的审计要求
   ——要能证明"当时为什么这样判断"
□ ⭐ 通用模型在这些领域表现最不稳定
   ——正是技能最能补的缺口
```

一个信号：Anthropic 官方的 `financial-services` 技能仓库
在短时间内涨到 +1,075 stars——**需求是真实的**。

## 共同结构

三个行业虽然规则不同，技能骨架一致：

```
1. ⭐ 适用范围声明（哪些能做，哪些必须转人工）
2. ⭐ 术语表（本行业内部口径）
3. 规则来源（法规/标准/内部制度，带版本与生效日）
4. 判定流程（可判定的条件分支）
5. ⭐ 输出契约（必须包含哪些字段）
6. ⭐ 禁止事项（红线）
7. ⭐ 溯源要求（每条结论的依据）
```

> ⭐ 第 3 条和第 7 条是垂直行业技能区别于一般技能的核心。

## 金融：可解释性与禁止编造

**核心红线**：

```
□ ⭐ 模型可以组织数字，不能生成数字
   ——所有数字必须能追溯到源数据
□ ⭐ 每个判断要给依据（哪条规则、哪个字段）
□ ⭐ 不确定就是不确定，不允许"合理推测"后当结论输出
```

**常见技能形态**：

```
□ 财报/交易数据提取与结构化
□ ⭐ 对账差异分析（要指出差异在哪一行）
□ 风险指标计算（口径必须写明）
□ 合规检查单（KYC/AML）
□ 客户沟通草稿（⭐ 不得承诺收益）
```

**一条特别值得抄的写法**：

```
指标定义必须含：
  ⭐ 计算逻辑 + 边界条件 + 常见误读
```

> 呼应 `pm-skills.md` 同一条：
> 只写"月活 = 当月活跃用户数"，不同人会算出三个不同数字。

## 医疗：隐私与不确定性的表达

**核心红线**：

```
□ ⭐ 患者标识信息处理（去标识化后再进入任何上下文）
□ ⭐ 不给出诊断结论，只做信息整理与提示
□ ⭐ 不确定性的表达必须分级
   （确定 / 可能 / 无法判断——不能用"应该是"）
□ ⭐ 引用临床指南要带版本与发布机构
```

**一个反直觉的实证**：

> ⭐ **医疗 agent 加了合规技能后，用户满意度反而提升 15%**
> ——合规不是成本，是信任信号。

呼应 `industry-patterns.md`（**`skill-selection`**）：
**38% 的"成功"其实是通过违规操作实现的**——
所以技能必须显式声明"不许做什么"，否则 agent 会用越界的方式达成"成功"。

## 法务：依据溯源与克制原则

**核心红线**（呼应 `legal-contract-skills.md`）：

```
□ ⭐ 每条依据必须写清：来源级别 · 标题 · 发布/生效日期 · 与结论的关系
□ ⭐ 检索说"未提及" → 标记"未验证——需人工复核"，绝不允许补全
□ ⭐ 克制原则：合同最终由人来签、推进、执行——人才是验收节点
     agent 的目标是把人的脑力消耗压到最低，不是源源不断地产出
```

**为什么法务的溯源要求最严**：

```
其他领域编错一个数字 → 一个错误结论
法务编一条不存在的法条 → ⭐ 整份意见书失效，且损害专业信誉
```

## 三条跨行业红线

**① 溯源字段不可省略**

```
□ 每个结论 → 依据来源
□ 每条法条/标准 → 版本 + 生效日期
□ ⭐ 找不到 → 明说"未找到"，不补全
```

**② 转人工的条件要可判定**

```
❌ "复杂情况交人工"
✅ "涉及跨境数据传输 → 转法务"
✅ "置信度 <0.8 → 进人工队列"
✅ "金额 >X → 人工复核"
```

**③ 输出要拆成"可用"与"待确认"**

```
□ 已验证的部分（带依据）
□ ⭐ 待人工确认的部分（明确标出）
□ ⭐ 未找到依据的部分（不能沉默）
```

> ⭐ **第三块最容易被省**——agent 默认会输出一个"完整"的答案，
> 把没找到的部分悄悄用推断填上。
>
> 呼应 `grounding-verification.md`（**`skill-crafting`**）：
> 要求 agent **说明"哪些它没有验证"**。

## 与通用技能的关系

垂直行业技能**不是**从零写的一套东西，而是：

```
通用技能骨架
  + 行业术语表
  + 外部规则来源
  + 行业特有的红线
  + 行业特有的输出契约
```

> ⭐ **先做好通用技能，再加行业层**——
> 反过来做会得到一堆不可复用的行业专属文件。
>
> 呼应 `instruction-layering.md`（**`skill-crafting`**）：
> **技能可以保持简洁，因为它从 bootstrap 层隐式继承了工作区约定**。
