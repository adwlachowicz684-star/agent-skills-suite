## 调研为什么会失败

官方总结的三种失败，都发生在**最后那页 PPT 之前**：

```
1. ⭐ 把几个响亮的评论当成一个市场
2. ⭐ 把竞品的定位陈述当成事实复述
3. ⭐ 让 AI 从稀薄证据里凭空造出确定性
```

> 第 3 条尤其值得记：
> **模型最擅长的事情（写出自信的结论）恰恰是这个场景最危险的**。
>
> 呼应 `research-skills.md`（**`skill-domain-eng`**）的硬护栏：
> **研究技能能悄无声息地制造权威感**——
> 一段流畅但来源糟糕的摘要，看起来会很可信。

## 六条评价标准

```
1. 任务清晰度（job clarity）
2. ⭐ 证据来源可见
3. 输出可行动
4. ⭐ 对缺失数据有诚实的边界声明
5. 上手成本相称
6. ⭐ 在更大调研流程中有清晰角色
```

**关键一句**：

> ⭐ **没有任何技能因为"假装能取代访谈、分析或专家判断"而得分。**

这条本身就是评价标准的元标准——
呼应 `eval-roles.md`（**`skill-evaluating`**）的
**"对一个薄弱断言给出通过，比毫无用处更糟"**。

## 八类调研技能与各自局限

| 技能 | 最适合 | ⭐ 重要局限 |
|---|---|---|
| **Niche Research** | 界定市场、找反复出现的痛点 | 主要是研究框架；结论仍需一手调研验证 |
| **Competitive Analysis** | 比较定位、信息、内容 | ⭐ 公开证据可能不完整或已过时 |
| **Product Review Analysis** | 提取客户语言与产品缺口 | 质量取决于评论样本是否有代表性 |
| **Social Listening** | 追踪社区近期讨论 | ⭐ 热门帖子 ≠ 代表性需求 |
| **SEO/GEO Keyword Research** | 发现搜索驱动的需求与内容机会 | 免费信号给不出可靠的量与难度 |
| **Reddit Content Retrieval** | 抓取原始帖子与评论 | 仍需去重与解读 |
| **People Search** | 找买家、专家、伙伴、创作者 | 需额度、授权与隐私合规 |
| **Amazon Sales Estimator** | 从市场代理指标估算品类需求 | ⭐ 估算值不是审计过的销售额或市场规模 |

> ⭐ **"重要局限"这一列是这类技能最该有的东西**。
> 没有它，agent 会把估算当事实输出。

**一个反复出现的模式**：

```
Niche Research 的产出应被视为"假设地图"，
⭐ 最强的模式还要通过访谈、观察到的行为、
   真实的交易或用量数据来确认
```

## 竞争分析的正确形态

**要覆盖的维度**（不是功能勾选表）：

```
□ 竞品档案
□ 信息传达（messaging）
□ 受众
□ 内容主题
□ 差异化
□ 优势 / 劣势 / 威胁 / 机会
□ ⭐ 建议动作
```

> ⭐ **"不要塌缩成一张功能对比表"** 是核心提醒。
> 功能表回答不了"哪些主张已经拥挤、
> 哪些买家焦虑没人管、我们能占据哪个可信立场"。

**两种实用输出格式**：

```
□ battlecard（给销售）
□ ⭐ messaging matrix（给产品与管理层）
```

## 必须写进技能的边界

**① 公开定位 ≠ 运营现实**

```
□ 竞品可能昨天刚改了定价、产品或目标细分
□ ⭐ 私下的赢单/丢单原因不会出现在它的首页
```

**② 给重要观察标日期**

```
❌ "竞品 A 主打中小企业"
✅ ⭐ "截至 2026-08（来源：其官网定价页），竞品 A 主打中小企业"
```

**③ 区分事实与推断**

```
□ ⭐ 已验证的事实（带来源与日期）
□ ⭐ 分析师的推断（明确标注）
□ 两者混在一起是这类技能最常见的失败
```

**④ 优先一手来源**

```
来源优先级：
  一手（官网、新闻稿、公开访谈、财报）
  > 可信二手（行业报告、媒体）
  > ⭐ 不可信（自媒体转述、无出处的数字）
```

**⑤ 保留客户的原话**

```
□ ⭐ "鼓励研究者保留确切的客户语言"
□ 这对访谈脚本和定位极有价值
```

呼应 `methodology-skills.md` 的文案原则与
`customer-support-skills.md` 的知识库字段要求。

## 调研类技能的通用骨架

```
1. 先选调研任务（job）
   ⭐ 更窄的技能通常比全能 agent 更容易验证

2. 明确要收集什么上下文、去哪里看

3. 如何归类发现

4. ⭐ 哪些局限必须披露

5. 输出格式（battlecard / 假设地图 / 主题清单）
```

## 与其他调研文档的关系

```
research-skills.md（domain-eng）→ 学术/文献类的硬护栏
本篇                            → ⭐ 市场/竞品类的证据分级
legal-contract-skills.md（domain-biz）→ 依据溯源（最严格的一档）
```

三者是同一条原则在不同严格度上的应用：
**结论必须挂在一个可独立验证的锚点上，且锚点要标日期。**
