> 问卷是最容易"看起来专业、实际无效"的产物。

## 设计阶段五原则

```
1. ⭐ 先写清"这个调研要决定什么"
   ——不能导向决策的题一律删掉

2. ⭐ 一题只问一件事
   ——"你对价格和客服满意吗"无法回答

3. ⭐ 选项中立且互斥且穷尽
   ——漏掉一个常见选项会逼受访者乱选

4. ⭐ 把敏感题放后面，人口统计放最后
   ——前面的回答会影响后面的

5. ⭐ 先做 5 人小规模预试
   ——预试能发现你以为清楚其实含糊的措辞
```

> ⭐ 第 1 条最该写进技能：
> **"删掉不能导向决策的题"是个可执行动作**，
> 而"问卷要简洁"不是。

## 题型选择

| 想了解 | 题型 | 注意 |
|---|---|---|
| 事实（年龄、用量） | 填空/单选 | ⭐ 给区间而非精确值（更好答、更准） |
| 频次 | 单选量表 | ⭐ 锚定要具体（"每周 2–3 次"而非"经常"） |
| 态度 | ⭐ Likert 量表 | 见下 |
| 排序/偏好 | 排序题或 MaxDiff | 排序题超过 7 项会失效 |
| 开放原因 | ⭐ 开放题 | ⭐ 放在具体题之后，不要放最后 |
| 无提示回忆 | 开放题在最前 | ⭐ 一旦给了选项就污染了 |

> ⭐ 最后一行是个专业细节：
> **品牌无提示认知度必须在给出任何选项之前问**。

## 量表设计

**Likert 的要点**：

```
□ ⭐ 用奇数还是偶数点（写死一种，全问卷一致）
□ ⭐ 每点都要有文字标签，不能只有端点
□ ⭐ 方向一致（不要前半份"同意=好"后半份反过来）
□ ⭐ 中立点要不要"不确定/不适用"
   ——"不适用"和"中立"是两回事，必须分开
```

**NPS 类单一指标**：

```
□ ⭐ 单一指标不能解释原因——必须配一道开放题问"为什么"
```

## 常见偏差

| 偏差 | 表现 | 修法 |
|---|---|---|
| **引导性措辞** | "您是否同意我们优秀的服务？" | ⭐ 中立表述 |
| **顺序效应** | 前面题目影响后面 | ⭐ 随机化（若工具支持） |
| **默认选项** | 预选某项抬高比例 | 不预选 |
| **社会期许** | 敏感问题报高 | ⭐ 匿名 + 间接问法 |
| **幸存者** | 只回收到极端意见 | ⭐ 记录回收率并说明 |
| **选项不穷尽** | 逼人乱选 | 加"其他（请注明）" |
| ⭐ **样本不代表** | 只听到最响的声音 | ⭐ 说明样本构成与局限 |

最后一条呼应 `market-research-skills.md`（**`skill-domain-biz`**）：
**热门帖子 ≠ 代表性需求**——同一条纪律。

## 分析阶段的纪律

**三条**：

```
1. ⭐ 先报告回收率与样本构成，再报告结论
   ——没有这个，结论无法判断可信度

2. ⭐ 区分"描述性结果"与"推断性结论"
   ——"62% 满意"是描述；"满意度提升了"需要对比基线

3. ⭐ 开放题要归类后计数，不要只挑有代表性的引用
   ——挑引用会放大极端意见
```

**置信区间的处理**：

```
□ ⭐ 样本量 <100 时要标注不确定性
□ ⭐ 分群后每群样本量可能只有十几个——不能下强结论
```

呼应 `ab-testing-growth.md`（**`skill-domain-biz`**）：
**忽略置信区间是分析阶段的三大错误之一**。

## 与相关技能的关系

```
market-research-skills.md → 竞品与公开信号
ab-testing-growth.md      → 实验验证（比问卷更硬）
customer-support-skills.md→ 被动反馈（工单）
本篇                      → ⭐ 主动提问获取
```

> ⭐ 注意强度排序：
> **实验 > 行为数据 > 问卷 > 访谈印象**。
> 问卷问的是"人们说自己会怎么做"，
> 实验看的是"他们实际怎么做"。
> 技能里最好写清这个排序，避免把问卷结果当成行为预测。
