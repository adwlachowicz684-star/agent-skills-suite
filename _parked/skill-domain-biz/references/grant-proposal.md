# 资助申请书（Grant Proposal）

> 一个"结构极强、可核对性极高"的写作场景。
> 技能的价值在于**不漏章节 + 对齐评审标准**。

## 十段标准结构

```
 1. 封面/标题页      项目标题、申请机构、负责人、申请金额与周期
 2. ⭐ 执行摘要（1 页）
 3. 需求陈述（2–4 页）
 4. 目标与指标（1–2 页）
 5. ⭐ 方法/项目设计（5–10 页）
 6. 评估计划（2–4 页）
 7. ⭐ 预算与预算说明（2–5 页）
 8. 可持续性计划（1–2 页）
 9. 机构能力（1–2 页）
10. 附录
```

**执行摘要的构成**（这一段最常被低估）：

```
□ 问题陈述（2–3 句）
□ 拟议方案（2–3 句）
□ 目标与预期成果（2–3 句）
□ 预算摘要（1 句）
□ 机构资质（1–2 句）
```

> ⭐ 页数分配本身就传递了信息：
> **方法部分占 5–10 页**，是最长的一节——
> 评审最关心"你具体怎么做"。

## 需求论证三要素

**① 量化问题**

```
□ 用本地、州/省、全国数据
□ ⭐ 引用权威来源（CDC、Census、WHO、同行评议）
□ ⭐ 展示趋势（问题在恶化吗）
□ ⭐ 与基准或均值比较
```

**示例句式**：

> "在本县，34% 的 5 岁以下儿童生活在食物不安全家庭，
> 而州均值为 19%、全国为 16%（USDA, 2024）。"

> ⭐ 这个句式值得作为模板：**绝对数 + 两个基准 + 来源 + 年份**。

**② 定义目标人群**

```
□ 人口统计（年龄、性别、收入等）
□ 地理位置
□ ⭐ 受影响规模
□ ⭐ 具体脆弱性或障碍
```

**③ 记录缺口**

```
□ 目前存在哪些服务/方案
□ 它们在哪里不足
□ ⭐ 哪些人群服务不到
□ ⭐ 支持拟议方案的证据是什么
```

呼应 `pii-data-handling.md`（**`skill-governance`**）：
涉及人群数据时**去标识化**，且示例用明显假数据。

## 目标要 SMART

```
□ 目标（goal）：宽泛、长期
□ ⭐ 指标（objective）：具体、可测量
□ ⭐ 与资助方优先事项对齐
```

> ⭐ "与资助方优先事项对齐"必须显式映射：
> **每一条目标后面标注它对应评审标准里的哪一条**。

呼应 `market-research-skills.md`（**`skill-domain-biz`**）：
**每条依据要能溯源**——这里是"对齐哪一栏"。

## 预算与可持续性

**预算部分**：

```
□ 逐项预算
□ ⭐ 预算论证说明（每项为什么需要）
□ 配套/成本分摊（如要求）
```

**可持续性计划**（1–2 页，最容易被写空）：

```
□ ⭐ 资助期结束后的筹资策略
□ 机构承诺
□ ⭐ 收入多元化
```

> ⭐ 评审看的是"这笔钱花完之后会怎样"。
> 没有可持续性的申请几乎必败——
> 技能里要把这一节的地位写清楚。

## 对齐评审标准

> ⭐ **这是资助类技能与其他写作技能的关键差异。**

```
□ 逐条对照评审打分表
□ ⭐ 每条标准在申请书中明确出现且有对应章节
□ ⭐ 用评审用的词，不用你自己习惯的词
```

**四类资助方的差异**（技能要能区分）：

```
政府资助  → 合规与指标最严
基金会    → 叙事与使命契合
企业      → 品牌关联与可量化回报
研究资助  → ⭐ 方法学严谨性
```

## 红线

```
□ ⭐ 不编造数据、引用或研究结果
□ ⭐ 不确定的数字标注"待核实"
□ ⭐ 涉及人群数据要脱敏
□ ⭐ 资助方的具体格式要求优先于通用模板
```

最后一条很实用——呼应 `what-not-to-do.md`（**`skill-authoring`**）：
**规则与实际情况冲突时以实际情况为准**。
