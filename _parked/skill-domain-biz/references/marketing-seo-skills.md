## SEO 审计该查什么

> ⭐ **五个维度**（写进技能让 agent 逐项过）：

```
□ 标题
□ 描述
□ ⭐ 结构化数据
□ ⭐ 内链
□ ⭐ 可爬取性
```

**何时使用**：

```
□ 需要 SEO 审计时
□ 优化页面 SEO 时
□ ⭐ 确保网站可爬取性时
□ 改进搜索排名时
```

**使用技巧**（四条，可直接抄）：

```
1. 让 agent 审计落地页的 SEO
2. ⭐ 获取"可执行修改清单"（而不是泛泛建议）
3. 优化标题和描述
4. 改进内部链接结构
```

> ⭐ **"可执行修改清单"是关键**——
> 呼应 `skill-crafting` 的 `guidance-forms.md`：**要配方不要禁令**。
> 审计报告的价值在于"第几行改成什么"，不是"SEO 有待加强"。

## 文案与润色的分工

> ⭐ **这两个要分开，因为触发场景和输出完全不同**：

| | `copywriting` | `copy-editing` |
|---|---|---|
| **做什么** | 营销文案、标题、CTA、卖点提炼 | ⭐ 语气统一、错别字、可读性、品牌话术 |
| **何时用** | 需要营销文案时 · 优化产品介绍时 | 统一品牌话术时 · 提升可读性时 |

**使用技巧**：

```
1. 让 agent 写产品介绍
2. ⭐ 优化邮件标题做 A/B 测试
3. 统一整站文案风格
4. 提升文案可读性和吸引力
```

> ⭐ 呼应 `pm-skills.md` 的 70% 生成 + 30% 定制：
> **生成与润色分成两个技能**，正好对应这两步。

## 营销心理学的用法

```
说服逻辑 · 紧迫感 · 社会认同
——应用于文案与页面设计建议
```

```
□ ⭐ 内容策略：内容规划、选题、发布节奏
□ ⭐ 营销创意：活动点子、推广角度、钩子设计
```

> ⚠️ **这类技能要注意边界**：
> 紧迫感与社会认同若使用不当会变成误导性设计。
> 技能应明确**不得虚构库存紧张、不得编造用户评价**
> （呼应 `legal-contract-skills.md` 的零幻觉策略与
> `writing-org-context.md` 的禁用表达清单）。

## 可直接抄的提示示例

```
"帮我审计这个落地页的 SEO，给出可执行修改清单。"
"如何优化这个页面的 SEO 表现？"
"写一个吸引人的产品介绍。"
"如何优化这个邮件标题？"
```

> ⭐ **这些"用户会怎么说"的原话，就该写进 description**——
> 呼应 `skill-authoring` 的 `creation-framework.md` 与 `skill-refining` 的 `i18n.md`：
> **用用户的真实说法，而不是作者的概括**。

## 自查

```
□ 是否逐项列出了审查维度（而非笼统"检查 SEO"）？
□ ⭐ 是否要求输出"可执行修改清单"（而非泛泛建议）？
□ 是否区分了"生成"与"润色"两个技能？
□ ⭐ 是否有"统一整站风格"这类团队向用法？
□ 是否提供了用户原话式的提示示例？
□ ⭐ 这些示例是否写进了 description（用于触发）？
□ 营销心理学类是否声明了边界（不虚构库存/评价）？
□ 是否说明了何时用（触发条件）而非只说能做什么？
□ 内容策略是否含发布节奏（可执行）？
□ 是否避免了把高度创意任务硬做成固定流程？
□ 品牌话术是否可独立更新（放 references/）？
□ 是否支持 A/B 测试对比（可判定产出）？
```
