> 真正的价值在**选题、复用与一致性**。

## 内容流水线

```
选题 → 大纲 → 初稿 → ⭐ 编辑 → 分发 → ⭐ 效果回收 → 选题
  ↑                                              ↓
  └──────────────────────────────────────────────┘
```

> ⭐ **最后那条回边是关键**——
> 没有效果回收，选题永远靠猜。
>
> 呼应 `ab-testing-growth.md`（**`skill-domain-biz`**）的
> 实验循环：**把赢家变成模式，进手册**。

## 选题的四个来源

```
1. ⭐ 客户真实提问（工单、销售通话、社群）
   ——最高质量来源：这些是真实存在的困惑

2. ⭐ 搜索需求（关键词、SEO/GEO）
   ——有量但要注意：免费信号给不出可靠的量与难度

3. 产品更新与发布
   ——必然要写，但容易变成功能播报

4. ⭐ 竞品内容缺口
   ——呼应 market-research-skills.md 的内容主题分析
```

**优先级规则**：

```
□ ⭐ 客户提问 > 搜索需求 > 竞品缺口 > 产品更新
□ 理由：前两类有真实需求证据，后两类更多是内部视角
```

## 一稿多用

> ⭐ **一次研究，多种形态**——这是内容效率的最大杠杆。

```
一份深度研究
  → 长文（官网/博客）
  → ⭐ 社媒拆解（5–7 条）
  → 邮件简报
  → 销售用的 battlecard
  → ⭐ 客户成功用的说明文档
```

**技能该写的**：

```
□ 每种形态的长度、语气、结构差异
□ ⭐ 哪些内容可以复用，哪些必须重写
   ——结论可复用；开头和 CTA 必须按渠道重写
```

## 编辑检查单

```
□ ⭐ 有明确的目标读者（不是"所有人"）
□ ⭐ 第一段的承诺与全文兑现的一致
□ 术语与品牌规范一致（术语表、禁用词）
□ ⭐ 每个断言有来源或标注为观点
□ ⭐ 有明确的下一步动作（CTA）
□ 长度符合渠道惯例
□ ⭐ 标题不含点击诱饵
```

呼应 `market-research-skills.md` 的**证据分级**与
`ux-writing-microcopy.md` 的**禁用词清单**。

## 不该做什么

```
❌ ⭐ 不发布未经验证的数据或引用
❌ ⭐ 不用 AI 生成的"案例研究"冒充真实客户案例
   ——这是内容类技能最危险的一条
❌ 不为凑数而产出——低质量内容损害品牌
❌ ⭐ 不把竞品的定位陈述当事实复述
❌ 不做无出处的竞品对比
```

> ⭐ 第二条值得单独强调：
> **虚构的客户案例和引用，在内容场景里的危害远高于其他场景**
> ——它是公开的、可追溯的、损害信任的。

呼应 `research-skills.md`（**`skill-domain-eng`**）的硬护栏：
**不准编造引用、引文、研究细节或数字**。
