## 1. ⭐ 从分析问题出发，不从图表类型出发

> ⭐ **先定义分析问题和结论，再选图表。**
>
> 常见错误是反过来——"因为出现了'trend'这个词，所以用折线图"。

正确顺序：先判断读者需要的是**状态、变化、差异、构成还是分布**，
再选最简单且站得住的图表族。

**默认兜底**：分类 → 条形图；连续 → 散点图。

**不要"动力不足"的图表**：

```
趋势图  至少 8–12 个时间点，少于此用 KPI 卡/分组条形/叙述
散点图  至少 12–20 个有意义的点
```

## 2. 图表选择表

| 数据关系 | 图表 | 用好的要点 |
|---|---|---|
| 随时间趋势 | 折线 | 点数足够揭示形状；面积仅在填充量级有帮助时用 |
| 随时间构成 | 堆叠面积 | 各部分应读作一个总数；比较轨迹时改折线 |
| 跨类别比较 | 条形 | 顺序无语义时排序；长标签用横向条形；避免冗余图例 |
| 排名 / Top-N | 排行榜 | 紧凑单指标；需要更多上下文时改排名条形 |
| 部分-整体 | 堆叠条形 | ⭐ 分母要明确；饼图只在少数切片的粗略阅读时用 |
| 分布 / 离散 | 直方图 | 数值分箱揭示形状；比较组间时用箱线图 |
| 跨组分布 | 箱线图 | 中位数与离散；需要看形状时用直方图 |
| 变量关系 | 散点 | 数值 x 和 y，点数足够呈现模式 |
| 密集 2D 模式 | 热力图 | 矩阵形状或强度；点级变化用散点 |
| 起止桥接 | 瀑布 | ⭐ 仅当驱动因素能干净加总到终值 |
| 有序阶段推进 | 漏斗 | 仅用于有序单序列；几何变形时用阶段条形 |

## 3. ⭐ 四个 gotcha（最有价值的部分）

这类技能最值钱的不是"怎么画图"，而是**模型容易犯的错**。

### ① ⭐ 截断条形图 y 轴

```
y 轴从 85% 起 → 3 个百分点的差异看起来巨大
```

> **条形图必须从零开始**，除非基线被明确标注且读者充分理解。
> 零无意义的场景改用点图或连接线做前后对比。

### ② ⭐ 双 y 轴暗示不存在的关系

```
两个序列放双轴，纯靠缩放就能看起来正相关或负相关
```

> **图表变成了误导工具而非告知工具。**
> 改用小倍数图（small multiples）或把两个序列索引到同一基线。

### ③ ⭐ 散点图过绘制掩盖真实分布

```
几百个点以上，重叠标记让密度不可见——
密集簇和稀疏簇看起来一模一样
```

> 用 alpha 透明、2D 密度（hexbin / KDE），或点数大时先聚合。

### ④ 饼图超过四片

```
人无法准确比较超过四段的弧长或面积
```

> 改用按值排序的横向条形图。

## 4. 颜色与无障碍

| 数据类型 | 配色 |
|---|---|
| 顺序（低→高） | 单色渐变或 viridis |
| 分歧（偏离中心） | coolwarm / RdBu，**以零为中心** |
| 分类 | 对比足够的区分色相 |

三条硬规则：

```
⭐ 绝不只靠颜色——加图案、标记或标签
⭐ 色盲友好调色板：seaborn "colorblind" / viridis / cividis
⭐ 限制在 7 种颜色以内，超出就分组或分面
```

无障碍底线（与 `a11y-skills.md` 一致）：

```
WCAG AA 对比度：文本 4.5:1，图形 3:1
静态图要有 alt text
交互图要支持键盘导航
⭐ 提供数据表作为兜底
```

> ⭐ **分享前用色盲模拟器测一遍。**

## 5. 标注与仪表盘布局

**标注**：

```
⭐ 标注洞察，而不只是数据点
标注有意义的最大/最小值、阈值或目标线、解释趋势变化的事件
2–3 个序列时用直接标签，不用图例
箭头从标签指向数据（不是反过来）
```

```
✅ "峰值：1,247（Q3 发布）"
❌ "最大值出现在第三季度"
```

**仪表盘布局**：

```
最重要的指标放左上（阅读顺序）
一致网格：2–3 列，同行卡片等高
筛选器在顶部，不要埋在单个图表里
⭐ 每个仪表盘都要有标题、日期范围、数据新鲜度指示
⭐ 每个仪表盘限制 6–8 个可视化——更多导致认知过载
```

**叙事**：

```
⭐ 先给结论："Q3 收入增长 40%"，而不是"这是一张收入图"
结构：背景 → 发现 → 影响
渐进披露：先摘要，再支撑细节
```

## 6. 静态 vs 交互

| | 场景 | 要求 |
|---|---|---|
| **静态**（matplotlib / seaborn） | 报告、论文、演示 | ⭐ 打印尺寸可读（12pt+ 字体、300dpi） |
| **交互**（plotly / Altair / D3） | 仪表盘、探索工具 | tooltip、密集数据缩放、筛选控件 |

> ⭐ **交互图必须提供静态兜底。**

## 速查

| 需求 | 图表 |
|---|---|
| 趋势 | 折线（≥8–12 点） |
| 比较 | 条形（排序，长标签用横向） |
| 分布 | 直方图 / 箱线 |
| 关系 | 散点（≥12–20 点） |
| 构成 | 堆叠条形（饼图 ≤4 片） |
| 拿不准 | 分类→条形；连续→散点 |

| 绝对不要 | |
|---|---|
| 截断的条形 y 轴 | 从零开始 |
| 双 y 轴 | 小倍数或共同基线 |
| 密集散点不处理 | alpha / hexbin / 聚合 |
| 只靠颜色区分 | 加图案或标签 |
