## 图表选型表

| 图表 | 适合 | 不适合 |
|---|---|---|
| **折线** | 随时间趋势、连续数据（股价、温度、流量）· 多序列对比 | — |
| **条形** | 类别比较、排名（按产品的销量、按国家的用户） | — |
| ⭐ **饼/环** | 部分与整体（市场份额、预算分配） | ⭐ **最多 5–7 块；精确比较请用条形图** |
| **面积** | 随时间体量、堆叠类别、累计总量 | ⭐ 重叠序列过多时 |
| **散点** | 相关性、离群点、分布 | ⭐ 时间序列 |
| **热力图** | 两个维度上的强度（时间模式、地理、矩阵） | ⭐ 简单比较 |

**按数据类型的推荐**：

```
时间序列      → 折线或面积
类别比较      → 条形（标签长时用横向）
占比          → 饼/环（最多 7 块）
相关性        → 散点
分布          → 直方图或箱线图
地理          → 热力图或分级统计图
层级          → 矩形树图或旭日图
流量          → 桑基图
```

> ⭐ 呼应 `skill-crafting` 的 `guidance-forms.md`：**这是"if <可观察谓词> then"的教科书用法**——
> 先把数据类型判出来，再查表选图，而不是让模型即兴发挥。

## 常见错误与修法

| ❌ 错误 | ✅ 修法 |
|---|---|
| ⭐ 固定宽高 | 用 ResponsiveContainer |
| ⭐ 实时数据上开动画 | `isAnimationActive={false}` |
| ⭐ 饼图切片过多 | 最多 5–7 块，其余归"其他" |
| 颜色不可访问 | ⭐ WCAG AA 合规 + 色盲安全调色板 |
| ⭐ 整包引入图表库 | 动态 import 懒加载 |
| ⭐ 不做数字格式化 | 用 `Intl.NumberFormat` 处理货币/百分比 |

> ⭐ **"实时数据上开动画"这条很少有人意识到**——
> 呼应 `frontend-ui-skills.md` 的动画规范与
> `skill-selection` 的 `performance.md` 的渲染开销。

## 仪表盘四种模式

| 模式 | 用例 | 关键特性 |
|---|---|---|
| **KPI** | 高管指标 | 趋势指示器、卡片网格 |
| ⭐ **实时** | 实时监控 | SSE/WebSocket、⭐ **动画关闭** |
| **交互式筛选** | 探索性分析 | 时间段/地区选择、下钻 |
| **下钻** | 层级数据 | 点击缩放（年 → 月 → 日） |

**响应式做法**：

```
□ 基于容器的尺寸（Container-based sizing）
□ 宽高比模式
□ ⭐ 移动端感知：在小屏上减小 strokeWidth 与高度
□ 标签简化：移动端减少坐标轴标签
```

## 决策树：先 profile 再画图

> ⭐ **不熟悉的 dataset 必须先 profile**——这是这类技能的第一步：

```
用户提供 CSV
├─ "profile/分析这份数据" / 不熟悉的数据集
│   └─ ⭐ 先跑 data_profile.py，再根据发现提供可视化选项
├─ "建仪表盘" / 需要多个图
│   ├─ 用户明确知道要什么图 → 写 JSON config → create_dashboard.py --config
│   └─ 用户想要自动仪表盘 → create_dashboard.py（自动模式）
└─ 指定了具体图（"直方图""散点图"）
    └─ visualize_csv.py 带对应参数
```

**profile 时要看什么**：

```
□ 列的数据类型与范围
□ ⭐ 缺失值模式
□ 数据质量问题
□ 统计分布
```

**常见报错与排查**（写进技能能省大量往返）：

```
"Column not found"  → 先跑 profiling 看确切列名
                     ⭐ CSV 列名大小写敏感
                     ⭐ 检查列名前后空格
图是空的或不对      → 核对数据类型（数值 vs 类别）
                     检查所绘列的缺失值
                     确认非 null 值足够多
脚本执行报错        → 核对依赖是否装了
```

> ⭐ **"先跑 profiling 看确切列名"** 是个很实用的编排细节——
> 它避免了 agent 凭猜测写列名然后反复报错。

**这类技能的目录结构**（脚本承担全部确定性工作）：

```
scripts/visualize_csv.py      各类图
scripts/data_profile.py       自动 profiling 与质量分析
scripts/create_dashboard.py   多图仪表盘生成
references/visualization_guide.md   选型指南
```

## 自查

```
□ 是否有图表选型表（按数据类型 → 推荐图）？
□ ⭐ 是否限定了饼图切片数（5–7）并给出替代（条形图）？
□ 是否列出了每种图的"不适合"场景？
□ ⭐ 是否要求实时数据关闭动画？
□ 是否用了响应式容器（而非固定宽高）？
□ ⭐ 是否要求色盲安全 + WCAG AA 调色板？
□ 是否要求数字格式化（Intl.NumberFormat）？
□ 是否要求懒加载图表库？
□ ⭐ 是否要求先 profile 再画图？
□ 是否有决策树（profile / 仪表盘 / 具体图）？
□ 仪表盘图数量是否限制（6–9）？
□ ⭐ 是否说明了输出格式的适用场景（HTML/PNG/SVG）？
□ 是否有常见报错排查（列名大小写、空格、空图）？
□ 确定性工作是否都在 scripts/ 里？
```
