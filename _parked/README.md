# 已归档：领域实例库（与「如何创建技能」无关，放旁边备用）

本目录含 3 个技能包、45 份文档。内容是**各领域的技术知识本身**，
不是「技能该怎么设计」——按你的要求从主套件切出。

## 切分标准

- **主套件（9 个技能）** = 如何创建技能
