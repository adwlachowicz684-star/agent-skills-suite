## 列表页该有什么

```
□ ⭐ 一句话说明解决什么问题（不是"一个强大的技能"）
□ ⭐ 3–5 条典型触发场景（用户原文，不是技术描述）
□ ⭐ 前置条件（需要什么工具/权限）
□ ⭐ 明确的不适用场景
□ 版本与更新日期
□ 许可证
□ ⭐ 安装命令（带版本后缀）
```

> ⭐ **"典型触发场景用用户原文"** 这条最常被忽略：
> 用户是照着自己会说的话来搜的，不是照着技术术语。

呼应 `naming-description.md`（**`skill-authoring`**）：
description 里也要写触发词——同一条纪律。

## 安装命令必须带版本

> ⭐ **`#vX.Y.Z` 后缀不是可选项。**

```bash
# ✅
npx skills add owner/repo --skill my-skill#v1.2.0

# ❌
npx skills add owner/repo --skill my-skill
```

**理由**（真实事故）：

```
不带版本后缀的一次覆盖，
导致所有依赖它的下游技能全部中断
```

呼应 `release-versioning.md`（**`skill-distribution`**）：
**所有安装命令都必须带 `#vX.Y.Z` 后缀**。

## 安装后要断言

> ⭐ **不要只看"安装成功"，要验证装进去的是对的。**

**三条断言**：

```
1. ⭐ 文件真的在预期路径
   ls ~/.claude/skills/<name>/SKILL.md

2. ⭐ 数量对得上
   ——防止扁平扫描时多发了一个（见下）

3. ⭐ 内容对得上
   ——让 agent 复述技能流程，对得上才算加载成功
```

第三条呼应 `reload-debug.md`（**`skill-evaluating`**）：
**改完让模型复述技能的流程**——对得上才算生效。

## 常见上架问题

| 问题 | 症状 | 修法 |
|---|---|---|
| **扁平扫描多发** | 装了 N 个，实际多出 1 个 | ⭐ 见下 |
| 文件名不对 | 找不到 SKILL.md | ⭐ 必须精确 `SKILL.md` |
| frontmatter 错 | 扫得到但不加载 | 用最小模板回退 |
| 名称冲突 | 与已有技能重名 | 改用更具体的名字 |
| 大小写 | 本地能跑，CI 上不行 | ⭐ macOS 不敏感，Linux 暴露 |

**"扁平扫描多发"这条值得展开**：

> ⭐ **测试夹具 `evals/files/SKILL.md` 会被当成真技能发布出去。**

修法：

```
□ ⭐ 按本质命名：widget-builder-SKILL.md（不是 SKILL.md）
□ ⭐ 安装后断言数量
```

呼应 `packaging.md`（**`skill-refining`**）。
