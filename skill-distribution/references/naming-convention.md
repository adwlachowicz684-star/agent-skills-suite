# 命名规范：名字是标识符，不是简介

> 命名看起来是小事，但它是**加载、路由、冲突、可发现性**四件事的交汇点。

## 硬约束

```
name 字段
  □ ⭐ 1–64 字符
  □ ⭐ 只能小写字母、数字、连字符
  □ ⭐ 不能以连字符开头或结尾
  □ ⭐ 不能有连续连字符（--）
  □ 不含 XML 标签
  □ ⭐ 不含保留字（"anthropic" / "claude"）
  □ ⭐ 必须与父目录名完全一致（含大小写，但 name 本身只允许小写）

文件名
  □ ⭐ 恰好 SKILL.md（大写 SKILL，小写 md）
```

违反的后果：

```
name 格式错 / 与目录名不一致  → ⭐ 加载时被静默拒绝
                                技能列表里看不到，也不报错
文件名大小写错                → 同上
```

> **静默失败是这类错误最贵的地方**——
> 你会花几小时去调 description，而问题在 name。

## 四条启发式

**① 用连字符分词，不用下划线或驼峰**

```
✅ terraform-plan-review
❌ Terraform_Plan_Review
❌ terraformPlanReview
```

**② 具体到能区分**

```
❌ code-review          ——会和别人的撞
✅ code-review-frontend
✅ code-review-security
```

**③ 别用"通用词 + 大领域"**

```
❌ helper / utils / tools / assistant
❌ coding / documents
```

理由同 `description-patterns.md` 里的"太宽"：
**通用名字会和一大片技能竞争，赢不了任何一场。**

**④ 长度适中**

```
✅ 2–4 个词
❌ 一个词（太宽）
❌ 六个词（没人会打出来）
```

## 动词优先 vs 名词优先

两种都常见，各有适用场景：

```
动词优先   "Diagnose..." / "Write..." / "Debug..."
           ⭐ 适合：动作明确的任务型技能

名词优先   "brand-guidelines" / "postgres-best-practices"
           ⭐ 适合：规范/知识/标准类技能
```

判据：**用户提到它时说的是"做某件事"还是"某个东西"？**

```
"帮我做个安全审查" → security-review（动词感）
"按品牌规范来"     → brand-guidelines（名词）
```

> ⭐ 注意：**name 只是标识符，真正决定触发的是 description**。
> 所以这里的动词/名词选择是为了**人可读**，不是为了让模型匹配。

## 命名空间

插件提供的技能有命名空间：

```
plugin-name:skill-name
```

> ⭐ **有命名空间的技能不会与用户/项目技能因同名冲突。**

所以如果你遇到同名冲突，冲突方一定是
**企业 / 个人 / 项目**这三档之一（见 `priority-conflict.md`）。

自定义命名空间约定（团队内部）：

```
team-name-skill-name      小团队够用
domain-subdomain-action   领域多时更清晰
```

⚠️ 但要注意：**前缀会吃掉 description 之外的可发现性**，
而且会让每个名字变长。**先确认真的需要再用。**

## 什么时候该改名

```
① ⭐ 与更高优先级的技能同名（被静默遮蔽）
② 与同层技能职责重叠，路由分不清
③ 技能的职责已经变了，名字不再描述它
④ 名字太宽，导致过触发
```

第 ① 条最常见，也最容易被误诊为"技能坏了"。

第 ③ 条值得单独说：
**技能职责漂移后不改名，是最隐蔽的一种技术债**——
所有人（包括模型）都按旧名字理解它。

## 改名的代价

改名 = 换目录名 + 换 `name` 字段，且：

```
□ ⭐ 所有引用它的地方都要改（其他技能、脚本、文档、eval 集）
□ ⭐ 已发布的版本要考虑迁移期（见 versioning-compat.md）
□ eval 集里的 skill 字段要同步
```

> 所以**第一次就取好名字**比事后改名便宜得多。

## 自查

```
[ ] name 与目录名完全一致？
[ ] 只有小写字母/数字/单连字符？
[ ] 不以连字符开头或结尾？无连续连字符？
[ ] 不含保留字？
[ ] 文件名恰好是 SKILL.md？
[ ] ⭐ 能用 2–4 个词说清它是干什么的？
[ ] ⭐ 和同层其他技能能区分开吗？
[ ] 没有与其他技能撞名（含更高优先级层）？
```
