# Hook：在模型推理之前就执行了

> ⭐ **Shell 指令在 hooks 里跑，
> 发生在模型对输出进行推理之前。**
> 这改变了整个威胁模型。

## 为什么这个顺序很关键

模型的安全判断发生在**推理时**——
它读到一段可疑指令，可以选择不执行。

但 Hook 不同：

```
Hook 里的 shell 指令
  → ⭐ 在模型看到任何东西之前就已经跑了
```

后果：

```
□ 模型没有机会拒绝
□ 人没有机会看见
□ ⭐ "指令层面的审查"对 hook 类攻击完全无效
```

> 所以：**审计第三方技能时，hook 是第一个要看的地方**，
> 优先级高于 SKILL.md 正文。

## 四类 Hook 事件

按名称（具体支持集因运行时而异）：

```
PreToolUse      ⭐ 工具调用之前——可以拦截
PostToolUse     工具调用之后
Stop            会话/任务结束前
SessionStart    ⭐ 会话开始——最隐蔽，你还没开始工作
```

风险排序：

```
SessionStart  ⭐ 最高 —— 你什么都还没做
PreToolUse    高   —— 每次工具调用都触发
PostToolUse   中
Stop          中
```

> ⭐ **`SessionStart` 是最危险的**——
> 它在你发出第一条消息之前就执行了。

## 审计 Hook 的三问

对每个 hook，问：

```
① 它跑什么命令？
② ⭐ 是否捕获或发送数据？
③ ⭐ 在什么事件上触发？（SessionStart 需重点关注）
```

红旗：

```
□ 命令里有网络访问（curl / wget / nc / DNS）
□ 读取环境变量、凭据文件
□ ⭐ 写入会话之外的位置
□ 命令被 base64 或 hex 编码过
□ ⭐ 触发事件是 SessionStart 且做了实质工作
```

最后一条值得强调：
**一个在 SessionStart 里做"实质工作"的 hook，
无论做什么都该被质疑**——正常的初始化不需要联网或读凭据。

## 退出码协议

这是最容易被搞错的一条：

```
exit 0  → 允许，继续
⭐ exit 2 → 阻止
exit 1  → ⭐ 只在日志里留个标记，不阻止
```

> ⚠️ **想拦住一个操作，必须退出码 2。**
> 退出码 1 看起来像"出错了"，但实际**不会阻止**。

这个设计很容易被误解为"非零即阻止"。
实际语义是：**1 是"有信息"，2 才是"否决"。**

配套：

```
□ 阻止时，stderr 的内容会被反馈给模型
  ⭐ 所以错误信息要写清"为什么被拦"和"该怎么做"
     ——让 agent 能自我纠正
```

## 权限边界

```
□ ⭐ Hook 以你的权限运行
□ Hook 能看到会话上下文
□ ⭐ Hook 不受 allowed-tools 约束
```

最后一条很关键：
**你在 frontmatter 里写了只读工具白名单，
并不妨碍 hook 执行任意命令。**

> ⭐ 这再次印证：`allowed-tools` 不是安全边界。
> **安全控制必须在工具层/系统层做**
> （见 `least-privilege.md`）。

## 清单

对任何含 hook 的技能：

```
[ ] 列出了所有 hook 及其触发事件？
[ ] ⭐ 每个 hook 的命令都能读懂（没有混淆）？
[ ] 没有任何 hook 在联网？
[ ] 没有任何 hook 读凭据或环境变量？
[ ] ⭐ SessionStart hook 有没有做实质工作？（有则需要解释）
[ ] 命令中无 /dev/tcp、/dev/udp、nc 等？
[ ] ⭐ 阻止逻辑用的是 exit 2 而不是 exit 1？
[ ] Hook 的写入范围限制在预期目录内？
[ ] 这个技能真的需要 hook 吗？
```

最后一条：**很多 hook 是可以不用 hook 实现的**。
能在 SKILL.md 里用指令表达的，就不要放进 hook——
因为 hook 不受模型审查，也不受你事后阅读。

## 一条权衡建议

> ⭐ **Hook 的价值是"强制性"——模型无法绕过。**
> 这正是它危险的原因，也是它有用的原因。

适用场合：

```
✅ 需要 100% 保证执行的规则（如"绝不能读 .env"）
✅ 需要在模型看到之前完成的事（如注入上下文）
❌ 只是"希望模型遵守的偏好"（→ 写进 SKILL.md 或 CLAUDE.md）
```

判断很简单：**这条规则你能接受它"通常"被遵守，还是必须"总是"？**
前者用指令，后者才用 hook。

## 与记忆的关系

一条相关但常被混为一谈的点：

```
记忆文件（CLAUDE.md / MEMORY.md）
  → ⭐ 只是上下文，不是强制配置
  → ⭐ 要强制阻止某行为，用 PreToolUse hook，别靠记忆文件
```
