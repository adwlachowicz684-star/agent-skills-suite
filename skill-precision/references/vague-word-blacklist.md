## 1. ⭐⭐⭐⭐⭐ 一层被跳过的检查

我们已有的检查是**形态层**的：

```
这句该用禁令？配方？槽位？条件分支？
```

但形态对了，词可能是空的：

```
✅ 形态正确（配方 + 槽位）
❌ "输出一份**详尽**的报告，包含**相关**的信息，
    **必要时**附上**适当的**建议。"
```

> ⭐⭐⭐ **形态检查会让它通过。它仍然等于什么都没说。**

> ⭐⭐⭐⭐⭐ **无具体判据的词，对模型等于没有约束——
> 因为模型会按自己的默认值去填充它们，
> 而它的默认值和你的期望大概率不同。**

## 2. ⭐⭐⭐⭐⭐ 黑名单与替换表

| ❌ 含糊词 | ⭐ 替换成 |
|---|---|
| 尽量 / 尽可能 | 明确写"必须"或删掉（⭐ 二选一，没有中间态） |
| 酌情 / 视情况 | `if <可观察谓词> then A else B` |
| 适当 / 合适 / 合理 | 给出具体阈值、格式或数量 |
| 相关 / 有关 | 列出具体字段或来源 |
| 必要时 / 如有需要 | ⭐ 删掉，或写明触发条件 |
| 详尽 / 全面 | 列出必须包含的 N 项 |
| 简洁 / 简要 | 给出行数或字数上限 |
| 及时 / 尽快 | 给出秒数或轮次 |
| 注意 / 留意 | ⭐ 改成动作，或删掉（"注意"不是动作） |
| 确保 / 保证 | ⭐ 改成可验证的检查（"跑 X，输出应为 Y"） |
| 等等 / 诸如此类 | 列全，或写明"至少包含以上各项" |
| 一些 / 若干 | 给数字 |
| 优化 / 改进 | 给出衡量指标与阈值 |
| 用户友好 / 优雅 | ⭐ 换成可观察的属性（无嵌套超过 3 层 / 无硬编码路径） |

> ⭐⭐⭐⭐ **这张表最有用的一行是最后一行。**
> "优雅""用户友好""高质量"这类词的问题不是含糊，
> 是**它们把审美判断伪装成了验收标准**——模型无法执行，只能猜。

## 3. ⭐⭐⭐⭐ 三类替换法

**① 给阈值**

```
❌ "函数不要太长"
✅ "函数不超过 30 行"
```

**② 给判据**

```
❌ "确保配置正确"
✅ "跑 validate.py，输出应为 0 errors"
```

**③ 给来源**（专治"相关/有关"）

```
❌ "收集相关的上下文"
✅ "收集：错误堆栈、最近 5 次提交、失败的测试名"
```

> ⭐⭐⭐ 三种方法的共同点：**替换后的句子，
> 两个不同的人读它会对"做没做到"给出一致答案。**
> 这就是可观察性的操作定义。

## 4. ⭐⭐⭐⭐⭐ 五类伪装成约束的词

比普通含糊更危险——它们**看起来像硬约束**：

| 词 | 为什么危险 | ⭐ 检验 |
|---|---|---|
| **"确保 X"** | 像约束，其实是愿望 | 改成"跑 Y 验证 X"了吗？ |
| **"不要忘记 X"** | 像禁令，其实依赖记忆 | 有机制保证吗（槽位/脚本/检查点）？ |
| **"重要：X"** | ⭐ 强调不是约束 | 删掉"重要："后，句子还有约束力吗？ |
| **"总是 / 永远 X"** | ⭐ 看似最强，实则最易被例外打开 | 有没有写例外？写了就等于没有 |
| **"检查 X"** | 没说检查什么、什么算不合格 | 有判据吗？ |

> ⭐⭐⭐⭐⭐ 第三行最值得记：**"重要："是一个零信息量的前缀**
> ——它增加字数、增加权威感，但不增加任何约束。
> ⭐ 如果删掉它句子就没约束力了，说明问题在句子本身。

第五行的典型：

```
❌ "检查输出格式"
✅ "检查文件名匹配 ^[a-z0-9-]+$；不匹配则报 FAIL 并给出实际值"
```

## 5. ⭐⭐⭐ 例外：哪些含糊是正当的

不是所有含糊都要删——**三条正当场景**：

| 场景 | 例子 | 为什么 |
|---|---|---|
| ⭐ 留给模型判断正是目的 | "选择最合适的方案" | ⭐ 你**故意**授权它决定 |
| 人类读者需要的软说明 | "本技能面向初学者" | 给人的上下文，不是给模型的指令 |
| 无法量化的领域 | "语气要专业" | 配上示例即为可观察 |

第三条的关键：**含糊词 + 示例 = 可观察**。
所以"语气要专业"单独出现是含糊，配一个示例后就有效——
这正是《skill-content》的 `skill-content/references/examples.md` 存在的理由之一。

> ⭐⭐⭐ **判据：这句含糊是你授权它决定，还是你懒得写清楚？**
> 前者留，后者改。

## 6. ⭐⭐ 机械检查

可以 grep 的最小集：

```bash
grep -nE "尽量|尽可能|酌情|适当|合适|合理|相关|必要时|如有需要|详尽|全面|简洁|及时|确保|注意|等等|一些|若干|优化|改进|优雅|用户友好|重要：" SKILL.md
```

> ⭐⭐⭐ **把它加进 CI，阈值设为 0。**
> 这是"把反复被违反的书面规则编码成校验器"的又一个实例——
> 我们在文档里说了十几次"禁用尽量酌情"，
> ⭐ 但只有变成一条 grep，它才会真的被执行。

配一条防止误伤的规则：**命中后先按 §5 判正当性，再改**。
机械检查负责"让你看见"，不负责"替你决定"。
