## 1. ⭐ 数量的黄金比例

| 任务复杂度 | 推荐示例数 | 说明 |
|---|---|---|
| 简单分类 / 提取 | **2–3 个** | 覆盖正常 + 边界 case |
| 中等（多步推理） | **4–6 个** | 覆盖主要分支路径 |
| 高复杂度（多轮对话） | **6–10 个** | 覆盖完整对话流程 |

**另一套命名口径**（可对照）：

```
Zero-shot  0       简单、定义良好的任务
One-shot   1       仅演示格式
⭐ Few-shot 2–5     ⭐ 模式学习——准确率/tokens 平衡
Many-shot  6–20    复杂分类——高准确率，高 token
```

> ⭐ 两条硬边界：
> ```
> ⭐ 超过 5 个收益递减
> ⭐ 3 个高质量样本能达到 5 个普通样本的效果，而 token 少 40%
> ```

> ⭐ 最后这条是本份文档最实用的一句：
> **数量与效果不是线性关系——先提质量，再考虑数量。**

## 2. ⭐ 质量三要素

每个示例**必须**包含三项：

```
① 输入   用户说了什么
② ⭐ 思考过程  ⭐ agent 应该怎么想（⭐ 最常被漏）
③ 输出   agent 应该怎么回答
```

示例：

```
用户输入：我想退掉上周买的那个耳机，订单号 ORD202607150023

思考过程：
1. 用户明确要退款，触发"退款处理"技能
2. 提供了订单号，可直接查询
3. 调用 search_orders(order_id="ORD202607150023")
4. 假定返回：已签收，7 月 20 日，在 7 天退款期内
5. 耳机属于可退款品类
6. 调用 submit_refund(...)

Agent 回复：已查到您的订单 ORD202607150023（蓝牙耳机，¥299）…
```

> ⭐ **中间的"思考过程"是很多人的盲点**——
> 只给输入→输出对，模型学到的是格式，**学不到判断路径**。
> 而这正是技能相对普通提示词最有价值的部分。

**3C 原则**（另一口径）：

```
Clear     格式明确
Concise   ⭐ 每个案例约 100 token
Coverage  ⭐ 包含典型 + 边界案例
```

## 3. 选择标准

```
多样性：
  · 覆盖全部输出类别
  · 输入复杂度与长度要有变化
  · ⭐ 至少包含一个边界案例

质量：
  · ⭐ 所有示例的输出必须正确
  · 示例应无歧义
  · 反映真实分布

相关性：
  · 与预期输入相似
  · 匹配目标领域
  · ⭐ 时敏任务用最近的示例
```

> ⭐ "至少包含一个边界案例"——这与 `common-mistakes-checklist.md`
> 的"负样本比正样本值钱"同源：**边界定义了适用范围**。

## 4. 排序策略

| 策略 | 实现 | 何时用 |
|---|---|---|
| **相似度** | ⭐ 最相似的放最后 | ⭐ 检索增强系统 |
| 难度梯度 | 简单 → 复杂 | 学习/教学任务 |
| 随机 | 打乱 | ⭐ 降低位置偏差 |
| 时效性 | 最近放最后 | 时敏任务 |
| 反向难度 | 复杂 → 简单 | 强调简单模式 |

> ⭐ 默认用**相似度排序（最相似的放最后）**——
> 因为**离任务输入最近的那个样本对输出影响最大**。

## 5. ⭐ token 优化

```
精简示例（用最小但完整的例子）  ⭐ 省约 25%
```

对照：

```
verbose: "The customer said 'This product is amazing!' which expresses positive sentiment"
concise: "'Amazing product!' → positive"
```

> ⭐ 省 25% 的同时**不损失信息**——
> 模型不需要那句解释，它需要的是映射关系。

## 速查

```
数量：
□ 简单 2-3 · 中等 4-6 · 复杂 6-10
□ ⭐ >5 收益递减
□ ⭐ 3 个高质量 = 5 个普通，token 省 40%

质量三要素：
□ 输入
□ ⭐ 思考过程（最常漏）
□ 输出
□ Clear / Concise(~100 token) / Coverage(含边界)

□ ⭐ 至少 1 个边界案例
□ ⭐ 所有示例输出必须正确
□ ⭐ 默认相似度排序（最相似的放最后）
□ ⭐ 精简示例省 25% token
□ 时敏任务用最近示例
□ 随机排序可降低位置偏差
```

**一句话**：

> ⭐ **示例只给输入→输出，模型学到的是格式；
> 加上思考过程，它学到的才是判断。**
