## 1. 跑完了，什么都没输出

```
用户：检查一下这几个文件有没有问题
助手：（列出文件、读取、分析）
助手：好的。
```

> ⭐⭐⭐⭐⭐ 没有错误、没有中断、没有"我做不到"——
> 它完成了所有动作，然后说了句"好的"。

这类失败的特征是**三个"没有"**：

```
① 没有任何错误
② 没有任何产物（没有文件、没有结构化输出）
③ ⭐⭐⭐⭐⭐ 没有任何"我没做"的声明
```

而用户侧的感受是"它好像没干活"——⭐⭐⭐⭐ 说不清哪里不对，因为确实没有错误可指。

---

## 2. 三条成因

| 成因 | 机制 |
|---|---|
| ⭐⭐⭐⭐⭐ 所有分支都有条件，没有默认分支 | 条件全不成立 → 什么都不执行 |
| ⭐⭐⭐⭐ 收集阶段有结果，输出阶段没被显式列出 | 中间产物留在上下文，没进输出 |
| ⭐⭐⭐⭐⭐ "如无问题则不输出"是显式指令 | 沉默是被要求的 |

第一条是 `conditional-branch-writing.md`（没有 else 的 if）的极端形态：
⭐⭐⭐⭐⭐ **那份讲的是"else 会被模型自己定义"，这份讲的是"else 是沉默"。**

第二条常见于两段式技能：

```
① 扫描并收集问题（做完了）
② 输出报告（正文只写了"输出报告"，没写报告里有什么）
```

> ⭐⭐⭐⭐⭐ 收集到 0 个问题时，第②步"输出报告"没有内容可输出——
> 而正文没有规定"0 个问题时报告长什么样"。

## 3. "没有问题就不输出"

这是一条看起来非常合理的指令，也是空输出最常见的**显式**来源：

```markdown
如发现的问题，逐条列出；如没有问题，无需输出。
```

> ⭐⭐⭐⭐⭐ 它把两种完全不同的状态合并成了一个动作：**沉默**。

```
状态 A：检查了 12 个文件，0 个有问题   ← 这是一个结论
状态 B：没能完成检查                    ← 这不是结论
```

输出上两者完全相同（什么都不说），⭐⭐⭐⭐⭐ **于是用户无法区分"干净"和"没查"。**

而模型倾向于把任何"没查出问题"都归入状态 A——因为那是一个完成的答案。

修法只需加半句：

```
⭐⭐⭐⭐⭐ "如没有问题，输出『已检查 N 项，未发现异常』——N 必填"
```

> ⭐⭐⭐⭐⭐ 那句输出同时解决了三件事：证明查过、给出分母、把沉默变成一个可验证的声明。

## 4. 空输出 ≠ 空结果

| | 是什么 | 示例 |
|---|---|---|
| ⭐⭐⭐⭐⭐ 空结果 | 一个答案 | "已检查 12 项，0 项异常" |
| ⭐⭐⭐⭐⭐ 空输出 | 不是答案 | （什么都没有）/ "好的" |

> ⭐⭐⭐⭐⭐ 空结果携带信息（查了、查了多少、结论是没有）；
> 空输出不携带任何信息，而它看起来"没什么问题"。

判断方法：⭐⭐⭐⭐⭐ **把输出删掉，用户能推断出"查过了"吗？** 不能 → 是空输出。

这也解释了为什么它和"静默失败"是同一族：
⭐⭐⭐⭐⭐ **空输出是唯一一种连"错"都算不上的失败——它根本没有产生可评价的东西。**

---

## 5. 为什么它最难排查

| 失败类型 | 信号 |
|---|---|
| 崩溃 | 报错 |
| 结果错 | 有输出、可比对 |
| ⭐⭐⭐⭐⭐ 空输出 | ⭐⭐⭐⭐⭐ **没有信号** |

三个后果：

```
① 遥测上看不到（没有 error，通常也不计为 failure）
② ⭐⭐⭐⭐⭐ 用户不会报 bug（"它好像没反应"很难描述，多数人只是不再用）
③ ⭐⭐⭐⭐⭐ 复现时它可能又正常了（取决于输入是否触发了空分支）
```

> ⭐⭐⭐⭐⭐ 所以它通常不是被"修"掉的，而是以"这技能不太好用"的名义被弃用——
> 而作者一直不知道原因。

---

## 6. 修法

```
① ⭐⭐⭐⭐⭐ 输出契约必须规定"空集时输出什么"
② ⭐⭐⭐⭐⭐ 条件分支必须有默认分支，默认分支必须产生输出
③ ⭐⭐⭐⭐ "无需输出"类指令必须改成"输出『已检查 N 项，无异常』"
④ ⭐⭐⭐⭐ 收集与输出分离时，输出阶段显式列出要写哪些字段（包括 0 值情况）
⑤ ⭐⭐⭐⭐⭐ 把"输出非空"作为断言写进 eval（最便宜的一条）
```

第⑤条值得单独强调：⭐⭐⭐⭐⭐ **"输出不为空"是所有断言里成本最低的一条，
而它恰恰是最常被漏的一条**——因为大家在断言"内容对不对"，没人断言"有没有内容"。

第②条与"没有 else 的 if"呼应：⭐⭐⭐⭐ **默认分支不只是"定义行为"，
它还是"保证有东西可输出"的唯一机制。**

---

## 7. 自检

| 检查 | 不通过的信号 |
|---|---|
| ⭐⭐⭐⭐⭐ 所有条件分支是否都有默认分支？ | 最后一个分支是 `if X` |
| ⭐⭐⭐⭐⭐ 空集时输出什么，写了吗？ | 没写 |
| ⭐⭐⭐⭐⭐ 有没有"无需输出/不必输出"类指令？ | 有 |
| ⭐⭐⭐⭐ 空结果声明里的分母必填吗？ | "未发现异常"（没有 N） |
| ⭐⭐⭐⭐ 收集阶段与输出阶段是否分离？ | 是，且输出阶段没列字段 |
| ⭐⭐⭐⭐⭐ 用一个"0 个问题"的输入跑一次，输出是空还是一句带 N 的声明？ | ⭐⭐⭐ 空 = 空输出 |
